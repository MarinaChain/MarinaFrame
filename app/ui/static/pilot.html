Proposed: GA revision pilot

One question: does checking and correcting MarinaFrame's work cost an engineer less time than doing the same basic-design change by hand? The pilot answers it on one real tanker design and one bounded change, with the time of every engineer step measured, review included.

Scope

  • One tanker design, with the yard's own lines plan, GA and tank plan.
  • Fixed hull. The hull form does not change; only the inside arrangement does.
  • One bounded compartment change, chosen by the yard's engineers. For example: move one transverse bulkhead by a stated number of frames, and resize the cargo and ballast tanks next to it.
  • Comparison with the baseline: every compartment, tank volume and check, before and after, side by side, each value linked to the drawing or the rule it came from.
  • Agreed constraint checks, written down with the engineers before the pilot starts (for example tank capacities, bulkhead positions, cargo tank size limits, ballast capacity). MarinaFrame reports each check with its numbers; it does not replace class approval.

Stages

  1. Baseline. MarinaFrame builds the GA, compartments and tanks from the drawings. Engineers check and correct it until they accept it as the starting model. Deliverable: the accepted baseline and the time it took.
  2. Bounded task. The engineers state the change in their own words. MarinaFrame revises the compartments and tanks and shows the difference from the baseline. Engineers check, mark what is wrong, and MarinaFrame revises again. Deliverable: the revised arrangement with its change record.
  3. Usable deliverable. Compartment drawing and 3D model (STEP), tank capacity and sounding tables, and the agreed checks as a report. Deliverable: files the engineers would use, or a clear list of why not.

What is measured

  • Total engineer time for each stage, review and correction included, against the engineers' own estimate (or record) for the same work by hand.
  • Number of corrections, time per correction, and how many needed a second try.
  • Which values were read from the drawings and which were guessed, and how many guesses were wrong.
  • Whether the stage 3 files were used as they were, used after edits, or not used.

Honest limits

  • Every output is a draft. Engineering approval stays with the yard and class; MarinaFrame never marks a design approved.
  • The pilot tests one design and one change. It does not show that every kind of change works.
  • If checking costs more than doing the work by hand, the pilot reports that.
