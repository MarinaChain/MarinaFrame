# Security

Run the workbench locally. It binds to localhost by default and is not designed as
an authenticated, multi-tenant internet service. Do not expose it publicly or load
confidential shipyard drawings into a shared instance without an independent
security review. Generated geometry requires qualified engineering review.

For suspected vulnerabilities, contact maintainers privately through an established
MarinaChain contact. Do not post credentials or confidential drawings in public
issues. This repository makes no support or response-time commitment.
