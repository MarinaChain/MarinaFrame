# Lane G: 3D view clean-up (2026-11-11)

Branch `lane/ui-3d-view` from `continue/v0.5`. UI only; no geometry output changes.

## User reports (Gunnerus run, Run tab)

1. Many thin translucent vertical sheets along the ship, about one per frame.
2. No clear control to see the internals.
3. Section strip tiles cut off with a scroll bar; the part fact card needs an inner scroll bar.
4. (Coordinator) The Spaces panel of an older run says only "No spaces yet".

## Causes and fixes

| # | Cause | Fix |
|---|-------|-----|
| 1 | `model3d.js buildSectionPlane` drew a plane (face 6 %, outline 55 %, 1.5 x beam by 1.5 x depth) at every section station. Gunnerus has 72 sections at 0.55 m frames. | Only the selected section has a plane. A new **Section planes** switch (key S) in the Show group draws all of them; only drawn planes can be clicked. Rule: `visibility3d.js sectionPlaneShown`. |
| 2 | The shell turned faint only when tanks or steel showed; no switch. | **See-through** button (key X, tooltip) in the Parts and spaces group: hull faint (10 %), parts, tanks and steel solid; steel shell plating also faint. Faint parts cast no shadow, show no cut face and let a click pass to the solid part behind. Rules: `shellPartOpacity`, `steelPartOpacity`. |
| 3a | `.strip` is `overflow-x: auto` with a min height of the tile row only. WebKit (the app's web view) leaves a plain horizontal scroll bar out of the flex item's height, so the bar ate the tile row and a vertical scroll bar appeared. Chromium adds the bar, so headless checks did not show it. | Styled 10 px strip scroll bar, `min-height` = tile row + bar, `overflow-y: hidden`. |
| 3b | `dock3d.cardMaxHeight` capped the card at 40 % of the pane, set once as an inline style (stale after a resize). | Cap removed; the card grows inside the side column and scrolls only in a pane too short for it. |
| 4 | Spaces come from GLB meshes with extras `kind: "tank"` (added in f6273e9, 2026-11-09). An older run's GLB has its tanks as plain parts, so there is no space. | The empty list says why (`spaces3d.js spacesEmptyReason`): no tank arrangement, no tank built, or a 3D model from an older build (run again). `workspace.js` passes the run's tank parts. |

Also: mock option `?mocksections=72` (72 sections, from -1.0 m) to reproduce the long strip.
