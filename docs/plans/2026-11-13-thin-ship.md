# Thin-ship Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a pure NumPy Michell wave-resistance estimate for explicit hull half-breadths.

**Architecture:** Keep the solver independent of CAD and empirical resistance. Integrate piecewise-bilinear offsets analytically in depth and length, then use Gauss-Legendre quadrature in t, lambda=cosh(t)=sec(theta). Return review-required quantities with explicit waterline, area basis, provenance and no engineering sign-off.

**Tech Stack:** Python, NumPy, pytest. No native kernel or new dependencies.

## Fixed exit gates (written before numerical runs)

1. Wigley parabolic hull: compare Cw with a published Michell-integral numerical tabulation for identical B/L, T/L, normalization and the complete published Fn range. Maximum relative error <=2%. An analytic independent implementation is a numerical cross-check, not a substitute for this gate. No invented reference values or graph readings presented as tabulations.
2. Speed: default evaluation <50 ms on this Mac; record repetitions, resolution and timing statistics, excluding geometry construction and convergence diagnostics.
3. Report only: KCS and KVLCC2 Cw versus published CT minus ITTC-57 Cf. Keep measurement scales and wetted-area bases identical; this residual includes viscous pressure and is not pure wave resistance. KVLCC2 is an established blind case; do not open its geometry, truth or measurements. Request PM-run evaluation instead.
4. Panel and angle convergence: report default versus doubled x/z sampling on an analytic Wigley surface and default versus doubled angle quadrature, plus increased tail limit. These checks quantify discretization, not model accuracy.

## Design review before implementation

- Architecture PASS: standalone module; no CAD imports or change to empirical estimator.
- Code quality PASS: SI coordinates; strict finite, ordered grids and nonnegative half-breadths; require closed ends and explicit sources. Reject immersed transoms instead of silently treating them as closed.
- Coverage WARN: published Wigley table still to be located. Test mathematical limits, scale law, independent analytic Wigley amplitude, record serialization and invalid inputs before claiming accuracy.
- Performance WARN: avoid a three-dimensional angle/x/z allocation. Use a depth-weight matrix and a longitudinal phase matrix. Cache only immutable quadrature nodes.

## Scope and sources

Base theory: J. H. Michell (1898), “The wave-resistance of a ship”, Philosophical Magazine 45, 106–123, DOI: https://doi.org/10.1080/14786449808621111.

No transom or boundary-layer displacement correction in version 1. They are optional in the brief, and adding an uncited empirical correction would make the physical scope less clear. Water is infinite-depth, inviscid and incompressible; symmetric slender hull, small slopes, steady translation, no trim/sinkage, no appendage interaction. Explicit input draft means depth below z=0 waterline; wetted reference area is caller-supplied, not inferred from projected area.
