# Thin-ship Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a pure NumPy Michell wave-resistance estimate for explicit hull half-breadths.

**Architecture:** Keep the solver independent of CAD and empirical resistance. Integrate piecewise-bilinear offsets analytically in depth and length, then use Gauss-Legendre quadrature in t, lambda=cosh(t)=sec(theta). Return review-required quantities with explicit waterline, area basis, provenance and no engineering sign-off.

**Tech Stack:** Python, NumPy, pytest. No native kernel or new dependencies.

4. Panel and angle convergence: report default versus doubled x/z sampling on an analytic Wigley surface and default versus doubled angle quadrature, plus increased tail limit. These checks quantify discretization, not model accuracy.

## Scope and sources

Base theory: J. H. Michell (1898), “The wave-resistance of a ship”, Philosophical Magazine 45, 106–123, DOI: https://doi.org/10.1080/14786449808621111.

No transom or boundary-layer displacement correction in version 1. They are optional in the brief, and adding an uncited empirical correction would make the physical scope less clear. Water is infinite-depth, inviscid and incompressible; symmetric slender hull, small slopes, steady translation, no trim/sinkage, no appendage interaction. Explicit input draft means depth below z=0 waterline; wetted reference area is caller-supplied, not inferred from projected area.
