# Head-to-head on sealed split hull-disjoint (v2): pre-registered protocol

Written 2026-11-08, before any reader output on the v2 split exists. Frozen code: `7c2d4f6`
(branch `continue/v0.5`). Manifest: `benchmarks/factory/manifests/sealed-v2/split_manifest.json`,
SHA-256 `856a37fad69439cd9fc83a75382699d5988323c0aa68ed9b1eaf66fcfdef81d3`.

## Question

Which policy should the app use by default: deterministic abstain, deterministic draft, or
LLM-first (DeepSeek, draft mode)?

## Arms

All arms use the same frozen source snapshot of `7c2d4f6` and byte-identical inputs from
`work/factory-sealed-v2/inputs/` (hashes checked against the manifest before the run).

1. **Abstain:** `--policy deterministic --on-ambiguity abstain`.
2. **Draft:** `--policy deterministic --on-ambiguity draft`.
3. **LLM-first:** DeepSeek autonomous policy with `--on-ambiguity draft`, the W11 investigation
   tools, the W12 setup proposal and veto review, and the W14 normalized coordinate frame, as
   they are at `7c2d4f6`. Same model and limits as the W11 live arm.

Each arm runs once on all 288 cases. A failed case (worker, provider, credential, timeout) is
counted as a failure. No retry may replace a result. No setting, gate, tolerance or prompt may
change after the first case starts.

## Measures (per arm, also split by layout and level L0-L3)

- Cases with a built CAD model, by final status (`awaiting_human_review`, `draft_not_verified`,
  `blocked`, `abstained`, failures).
- **Correct:** the frozen factory gate (2% RMS half-beam and 5% in-range volume), scored by the
  existing independent scorer after the arm finishes.
- **Silent wrong build:** final status `awaiting_human_review` with a valid model that fails the
  gate. This is the most serious failure.
- **Labelled wrong draft:** `draft_not_verified` that fails the gate.
- Open guesses per case, lines read per case.
- Model use: requests, prompt and completion tokens, list cost, failures.
- Wall time.

## Decision rule (fixed now)

- Any silent wrong build in an arm is reported first and blocks that arm from becoming default.
- LLM-first becomes the app default only if it has **at least as many correct cases as
  deterministic draft** and **no silent wrong build**.
- Else deterministic draft is the default if it has more correct cases than abstain and no
  silent wrong build; LLM-first stays an explicit option.
- Else abstain stays the default.
- Ties are broken toward the arm with fewer labelled wrong drafts.

## Reporting

Results go to `docs/BENCHMARK_FACTORY.md` (new section "Head-to-head, hull-disjoint (v2)") with
the broad-family caveat. Compact per-case rows go to `outputs/h2h-sealed-v2/`. Truth arrays,
drawings and credentials are never committed. This split is now spent for model selection: any
later tuning needs a new held-out split.
